MAIL-FINDER — iPhone Web-App/PWA

Diese Dateien bilden eine installierbare Web-App. Sie generiert lokal Kandidaten und exportiert sie als TXT. Keine Kontoprüfungen und keine automatisierten Anmeldeversuche.

WICHTIG: Für „Zum Home-Bildschirm“ mit eigenem App-Symbol muss die App über eine HTTPS-Adresse erreichbar sein. Eine ZIP-Datei oder eine lokal geöffnete HTML-Datei kann nicht als vollwertige PWA installiert werden.

iPhone:
1. Dateien auf einen HTTPS-Webhost hochladen (z.B. eigener Webspace).
2. Die HTTPS-Adresse in Safari öffnen.
3. Teilen > Zum Home-Bildschirm > Hinzufügen.
4. Danach startet Mail-Finder wie eine App.

WEB.DE-Kontowiederherstellung bitte nur über die offiziellen Hilfeseiten durchführen.
